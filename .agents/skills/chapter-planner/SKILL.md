# 章节与场景规划

## 输入

- 已批准的全书大纲与当前卷纲
- 最近章节摘要、人物状态和未完成情节线
- 相关正史、时间线和线索

## 章节卡

必须明确：

- 唯一主要功能、POV、时间和地点
- 开场状态、章节目标和主要阻力
- 3 至 6 个因果相连节拍
- 中段升级、不可逆选择和结尾状态
- 正史引用、线索引用、必须包含和必须避免

## 场景卡

每个场景使用：

`目标 → 阻力 → 尝试 → 升级 → 决定 → 结果`

反应场景可使用：

`余波 → 重新理解 → 选项 → 决定 → 新目标`

## 门禁

- 章节结束后至少一种状态改变。
- 不让角色使用未知信息。
- 不提前兑现标记为延后的秘密。
- 作者确认章节卡后，才交给 `$context-assembler`。
