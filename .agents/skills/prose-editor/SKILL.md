# 文笔诊断与修订

## 阶段一：只诊断

读取：

- `novel/brief/style_bible.yaml`
- 相关人物语言指纹
- 当前草稿
- 已通过的连续性报告

每项问题输出 ID、类型、严重程度、位置、文本证据、违反规则、最小建议和必须保护的事实。写入 `novel/reports/style/`。

## 阶段二：只修复获批问题

作者明确给出问题 ID 后：

1. 锁定事实、事件顺序、线索时机、人物决定、POV 和术语。
2. 依次处理人物声音、场景节奏、句法措辞和重复模式。
3. 只修改问题 ID 指向的最小范围。
4. 输出 diff 或直接更新 `draft.md`，不得覆盖 `final.md`。

## 停止条件

- 每章最多两轮结构修订和两轮语言修订。
- 新一轮必须解决明确问题。
- 新版本没有改善目标指标时保留旧版。
- 不以机械禁词替代上下文判断。
