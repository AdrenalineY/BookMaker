# 连续性审校

## 先运行

```powershell
.tools\uv\uv.exe run scripts\validate_project.py --root .
```

## 检查顺序

1. 正史和术语。
2. 时间、持续时长、因果与移动。
3. 人物位置、伤势、物品和资源。
4. 角色知识、秘密和叙述权限。
5. 线索种植、推进和兑现时机。
6. 章节开场与结尾状态差异。

## 报告格式

每项问题必须有：

- 问题 ID 和类型
- 草稿证据
- 冲突的权威证据
- 严重程度：致命、明显、轻微或疑似
- 最小修复方案
- 是否需要正史变更

没有明确证据时标记为疑问，不把个人偏好写成错误。报告写入 `novel/reports/continuity/`。
