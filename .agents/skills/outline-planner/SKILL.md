# 长篇大纲规划

## 输入

- `novel/brief/`
- 已批准的世界规则与人物卡
- `novel/outline/thread_ledger.yaml`
- 已定稿章节摘要和状态

## 工作流

1. 明确核心戏剧问题、读者承诺和结局方向。
2. 先确定触发、中点、低谷、高潮和结局，再填充经过。
3. 每个节点写明目标、选择、阻力、代价、状态变化和下一步压力。
4. 建立承诺、推进、兑现表。
5. 全书保留宏观节点，当前卷细化，未来 3 至 5 章详细规划。
6. 标记固定节点与可滚动调整节点。

## 质量门禁

- 后一个重要事件尽量由前一个选择造成。
- 反派和配角必须有独立行动线。
- 连续章节不得重复同一种功能。
- 大纲中的 `APPROVED` 才具有约束力；正文事实优先于旧计划。
